About Me

I'm a passionate game developer and 3D environment artist.
Mostly self-taught, mostly obsessed with bringing "digital worlds to life" or something like that.

I'm just a kid from India — with a laptop, a dream,
and the stubbornness to chase it all the way to the top, or atleast I hope so I get somewhere near.

I spend my nights modelling 3D environments, suffering in a loop of trial and error fixing that one script,
testing mechanics, writing even more messy code, and fixing it at 3 AM (still failed lol).

What for?
To build something real.
Something I can be proud of. An actual game brought from my imagination

I'm currently working on a 3D game — my biggest project so far(well its not like some huge thing but we all start somewhere right?).
I'm also preparing for the SAT, with hopes of making it to MIT, a lot of hopes to be honest.

It's a long road, and a tiring one infact.
But I've got time, passion, and some caffeine.

Let's see how far I can go.
